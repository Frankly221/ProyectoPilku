# Pillku Rooftop

Prototipo básico y responsive de una página web para Pillku Rooftop, Huarmey.

## Abrir localmente

Abre `dist/index.html` en un navegador. No requiere instalación ni compilación.

La carta, los precios, los eventos, el horario y la dirección exacta son datos ilustrativos o pendientes de confirmación.
